# Проект автоматизации тестирования API Яндекс Самокат

Этот проект содержит автоматизированные тесты для REST API учебного сервиса **Яндекс Самокат**. Тесты покрывают логику создания курьеров, их авторизации в системе, а также процесс создания и управления заказами.

## Используемый технологический стек

* **Python 3.10+** — основной язык разработки.
* **Pytest** — тестовый фреймворк для сборки и запуска тест-кейсов.
* **Requests** — библиотека для отправки HTTP-запросов к API.
* **Faker** — библиотека для генерации случайных реалистичных тестовых данных (имена, телефоны, адреса).
* **Allure Report** — инструмент для генерации наглядных и понятных графических отчетов о прохождении тестов.

## Покрытый тестовый функционал

1. **Логин курьера (`POST /api/v1/courier/login`):**
   * Успешная авторизация с валидными данными (возвращает `id`).
   * Проверка обязательности полей `login` и `password` (с применением параметризации).
   * Ошибка при передаче неверного логина или пароля (`404`).
   * Ошибка при попытке входа под несуществующим пользователем.

2. **Создание заказа (`POST /api/v1/orders`):**
   * Создание заказа с динамическими данными через `Faker`.
   * Параметризованный тест на выбор различных цветов самоката (`BLACK`, `GREY`, оба цвета одновременно, без выбора цвета).
   * Проверка тела ответа (наличие ключа `track`).

3. **Очистка данных (Tear-down):**
   * Все созданные во время тестов сущности (курьеры и заказы) автоматически удаляются/отменяются методами `teardown_class` и `teardown_method` после завершения проверок, оставляя тестовую базу чистой.

## Как запустить тесты локально

### 1. Подготовка окружения
Клонируйте проект и установите зависимости из файла `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 2. Запуск всех тестов
```bash
pytest tests/ -v
```

### 3. Запуск конкретного файла с тестами
```bash
python -m pytest tests/test_login_courier.py
```

## Генерация отчетов Allure

1. Чтобы запустить тесты со сбором результатов для Allure, выполните:
```bash
python -m pytest --alluredir=allure-results
```

2. Для генерации отчета и открытия его локальной версии в браузере введите команду:
```bash
allure serve allure-results
```
